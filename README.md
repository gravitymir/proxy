# proxy

*An application-level proxy, DHCP server and DNS sinkhole in one Windows exe, written in Rust (tokio).
It shares a PC's internet connection with devices behind a router and blocks ads and trackers.*

Раздача интернета компьютера устройствам за роутером через **прокси уровня
приложения** — когда обычная раздача (ICS / NAT) недоступна или не работает.
Плюс **DNS-синкхол**, который режет рекламу и трекеры (~76 тыс. доменов).
Всё в одном `socks5.exe` под Windows.

```
Телефон → роутер (WAN 192.168.137.2) → кабель → ПК 192.168.137.1
                                                ├─ прокси  :1080  SOCKS5 + HTTP → интернет ПК
                                                ├─ DHCP    :67    выдаёт роутеру его адрес
                                                └─ синкхол :53    режет рекламные домены
```

Прокси не пересылает чужие пакеты, а **сам открывает соединения от имени ПК**.
Для внешней сети это обычный трафик компьютера.

## Возможности

- **Прокси SOCKS5 + HTTP на одном порту** — протокол определяется по первому
  байту. HTTPS идёт туннелем через `CONNECT`: прокси не расшифровывает трафик,
  сертификаты не нужны. Подходит для «ручного прокси» в настройках Wi-Fi
  Android / iOS.
- **Мини-DHCP** для WAN-порта роутера. Отвечает **только** указанным
  MAC-адресам и шлёт ответы только в сеть кабеля, поэтому не мешает другим
  сетям, к которым подключён ПК.
- **DNS-синкхол** (отдельный крейт [`dns_sinkhole`](dns_sinkhole/)): домен из
  списка получает ответ «не существует» (NXDOMAIN), остальное уходит
  вышестоящему DNS. Слушает IPv4 и `[::1]`, иначе Windows обходит его через
  IPv6-DNS.
  - список [StevenBlack/hosts](https://github.com/StevenBlack/hosts) вшит в
    exe; если рядом лежит `blocklist_hosts.txt`, используется он;
  - **автообновление**: файл старше 7 дней — скачивается свежий. Если в ответе
    меньше 10 тыс. доменов (например, вместо файла пришла страница входа
    Wi-Fi), список не трогается. Замена атомарная;
  - список перезагружается **на лету**, без перезапуска и без перерыва DNS.
- **Один exe, два процесса**: синкхол — это тот же exe, запущенный с флагом
  `--sinkhole`, без своего окна. Его лог печатается в окне главного процесса
  голубым с отступом `│`. Упал — перезапускается через 3 с.
- **Аккуратный жизненный цикл**:
  - при старте DNS компьютера переключается на синкхол (только когда тот уже
    отвечает), при выходе возвращается в автоматический режим;
  - выход ловится системным обработчиком (Ctrl+C, закрытие окна, выход из
    системы, выключение), откат выполняется синхронно;
  - **Job Object**: если главный процесс убит как угодно (хоть из диспетчера
    задач), Windows сама завершает дочерний — порт 53 не остаётся занятым;
  - **«чёрный ящик»** `socks5.dns_switched`: следующий запуск видит, что
    прошлый упал и не вернул DNS, и пишет об этом. Если синкхол на этот раз не
    поднялся, DNS возвращается сразу, чтобы ПК не остался без интернета;
  - второй экземпляр видит занятый порт и закрывается, ничего не трогая.
- **Трафик в реальном времени**: скорость ↓/↑ в заголовке окна раз в секунду,
  сводка в логе раз в 10 секунд (в простое не печатается).
- Значок и манифест «требовать права администратора» вшиты в exe.

## Требования

- Windows 10 / 11.
- Rust 1.85+ (edition 2024), toolchain MSVC.
- Windows SDK (`rc.exe`) — им `build.rs` вшивает значок и манифест.
- Права администратора: программа переключает DNS через `netsh`.

## Сборка

```powershell
cargo build --release              # socks5.exe
cargo build --release --workspace  # + отдельный dns_sinkhole.exe
```

## Установка и автозапуск

Боевая копия ставится в `C:\Program Files\socks5`. Автозапуск идёт с правами
администратора без вопросов UAC, поэтому exe должен лежать там, куда может
писать только администратор: иначе его можно тихо подменить.

В терминале **от администратора**, из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1
```

Скрипт копирует exe (списки — только если их там ещё нет, чтобы не затереть
ваши правки) и создаёт задачу Планировщика `socks5 proxy`: при входе в Windows,
через 10 с, в видимом окне, без ограничения времени работы.

- запустить вручную: `schtasks /run /tn "socks5 proxy"`;
- обновить: `cargo build --release`, затем снова `deploy.ps1`, затем Ctrl+C в
  окне программы и запуск заново;
- удалить всё: `uninstall.ps1`.

## Настройка

Под свою сеть поправьте константы в коде:

| Что | Где |
|---|---|
| Порт прокси | `LISTEN` в `src/main.rs` |
| MAC роутера, адреса DHCP | `ALLOWED_MACS`, `SERVER_IP`, `CLIENT_IP` в `src/dhcp.rs` |
| Вышестоящий DNS для синкхола | `SINKHOLE_UPSTREAM` в `src/sinkhole.rs` |
| Сетевой интерфейс, чей DNS переключается | `WIFI_IF` в `src/control.rs` |
| Дополнительный список прокси | `blocklist.txt` (подстрока в имени хоста) |

Сеть:

- **ПК**: на кабельном адаптере статический `192.168.137.1/24` без шлюза, ICS
  выключен. В брандмауэре разрешены TCP 1080 и UDP 53 (только на кабельном
  интерфейсе).
- **Роутер**: WAN — `192.168.137.2/24`, шлюз и DNS `192.168.137.1`. Можно
  оставить статикой или «автоматически» — DHCP выдаст то же самое.
- **Телефон**: Wi-Fi → прокси вручную → `192.168.137.1`, порт `1080`.
  Веб-интерфейс роутера открывается только с выключенным прокси.

## Структура

```
src/main.rs        прокси (SOCKS5 + HTTP), запуск всего остального
src/dhcp.rs        мини-DHCP для WAN-порта роутера
src/sinkhole.rs    дочерний процесс-синкхол: запуск, лог, перезапуск
src/control.rs     DNS ПК: переключение, откат, «чёрный ящик», выход
src/update.rs      расписание автообновления списка
src/traffic.rs     перекачка данных с подсчётом, скорость
src/win.rs         WinAPI: Job Object, сигналы консоли, цвета, заголовок
dns_sinkhole/      крейт синкхола: библиотека + отдельный exe (--update)
build.rs           значок и манифест
assets/            значок и скрипт, который его рисует
deploy.ps1         установка в Program Files + автозапуск
uninstall.ps1      удаление
```

## Если что-то сломалось

Программу убили жёстко, и на ПК нет интернета — верните DNS (от администратора):

```powershell
Set-DnsClientServerAddress -InterfaceAlias 'Wi-Fi' -ResetServerAddresses
```

## Ограничения

- Работает только для клиентов, у которых прокси указан явно (не прозрачный).
- Рекламу внутри видео YouTube так не убрать: она приходит с тех же серверов,
  что и само видео.
- Пользуйтесь там, где правила сети разрешают раздачу подключения.
